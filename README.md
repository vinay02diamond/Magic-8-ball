# Magic 8-Ball 🎱

A simple Magic 8-Ball web application that provides answers to yes/no questions.

## 📝 Description
This project is a fun and interactive web-based Magic 8-Ball game. Users can enter their name, ask a yes/no question, and receive a random response. 

## 🚀 Features
- Enter your name for a personalized greeting.
- Ask any yes/no question.
- Get a random answer from the Magic 8-Ball.
- Simple and elegant UI with smooth animations.
